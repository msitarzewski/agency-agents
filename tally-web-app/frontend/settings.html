Tally Prime Setup Checklist

  1. Tally Prime → F1 (Help) → Settings → Connectivity → "TallyPrime acts as" = Both (or Server)
  2. F12 → Advanced Configuration: "Allow XML Server on Port" = Yes, Port = 9000
  3. Same screen: "Allow ODBC" = Yes, Port = 9001
  4. Windows ODBC Data Sources (64-bit) → System DSN → Tally ODBC 64-bit
  5. Keep Tally running with the target company open, then hit Test Connection
Settings persist in backend/data/settings.json
