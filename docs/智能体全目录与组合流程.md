## 使用说明

- 上表中的智能体**英文名称**与各文件 `name` 字段一致，便于在 Claude / Cursor 等工具中点名。  
- 若某流程中的角色与你的行业不匹配，可在同一分类目录中**替换为相近专家**（例如工程线的不同栈专家）。  
- 更细的阶段说明见 `strategy/playbooks/` 与 `strategy/runbooks/`。
