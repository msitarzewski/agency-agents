# gstack skills (Cursor)

Skill folders here are **copies** of `gstack/<skill>/` (with truncated frontmatter descriptions) created by:

```powershell
.\scripts\install-gstack-cursor-skills.ps1
```

Re-run after updating the `gstack` submodule/repo. For browser binaries, run `gstack/setup` once (Git Bash or WSL).

See **`.cursor/docs/gstack-rei-integration.md`** for how gstack fits the REI workflow.
